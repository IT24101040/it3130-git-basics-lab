 # IT3130 Git Basics Lab

## Purpose
This repository demonstrates a basic Git workflow for IT3130.

## Files
- HelloWorld.html - a small web page used to practise version control
- README.md - project documentation

## Commands practised
git init, git status, git add, git diff, git commit, git log, git remote, git push

## What I learned
I learned that the staging area lets me choose which changes to include before committing. Commits create permanent snapshots of my project with clear messages so I can track progress. Connecting to a remote repository on GitHub allows me to back up my work and share it safely.
